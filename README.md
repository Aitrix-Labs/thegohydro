# GoHydro (gohydro.com)

React + Vite site for **gohydro.com** — dark teal / lime brand system, full-bleed hero carousel, wave motifs, water storage stats, stories rail and careers CTA. Visual language inspired by modern renewable-energy utility sites.

## Run

```bash
npm install
npm run dev
```

## Stack

- React 19 + TypeScript
- Vite
- React Router
